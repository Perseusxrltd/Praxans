## What changes

An awake adult's local choice can select self-maintenance or assistance across kinship and community boundaries. Actual hunger, hydration, energy, sickness and sleep constrain work. A communal reserve target alone no longer excludes a useful care choice. Newly selected tasks earn nothing until they have paid an ordinary active tick's costs. Separation, travel, death or an interrupted task invalidates queued work.

Fiber comes from the actor's accessible stockpile or carried work cargo. Competing stock claims share the available amount; placements and removals have separate gross budgets. Every source is debited before any removal is returned, so that fiber cannot be reused during the same boundary. Progress records kilograms actually moved. Failed work cannot accumulate credit or material, and a removed covering cannot overwrite unrelated cargo.

Local target estimates use the same signed heat/shelter calculation as physiology. Feedback attributes each actor's actual thermal contribution instead of rewarding everyone for a shared outcome. Performed opposing self-adjustment can end a helper's current task and trigger another ordinary choice; silence, sleep and private intent are not a permission signal. The browser names the helper's actual recipient and completed material movement, and shows each body's current fiber mass.

The populated migration initially exhausted its protected heap. The loader retained the old 21.5 MB population JSON while serializing the upgraded checkpoint. It now keeps only that row’s checksum after parsing. The earlier `body-maintenance-20261008-1` artifact was rejected on a disposable world; it was never published. The final revision also passes 36 targeted body/migration/persistence checks after this memory correction.

## Explicit limits

The reference work rate is 0.4 kg/hour. New target planning uses the inherited 2 kg adult reference scaled by represented body area; it is not a physical mass ceiling. Choices retain heuristic probabilities and the existing age-12 work threshold. One occupied 100 m² cell approximates contact. The first observer's thermal estimate is reused within that cell for the quarter-hour; current contact and supplies are checked again. Fine manipulation, garments, spoken requests, feeding, carrying children and broader medicine are not represented by this change.

The conservation and ordering guarantee applies to body transfers. Sequential communal food allocation, rapid childhood growth, the baseline heat estimate and body-reserve/starvation accounting remain unresolved. Short controlled protection and successful migrations do not establish seasonal or generational viability. All four renewed communities remain extinct; no further renewal is part of this release.
