## Why these changes are needed

Raw regional checkpoints nearly fill the finite service volume with one SQLite write log. Regions now use lossless Zstandard frames when smaller, retaining the exact original JSON bytes and checksum plus a separate encoded-payload checksum. Plaintext fallback avoids expansion. The reader bounds content and window size and rejects incomplete, conflicting or unknown encodings before accepting state. Legacy regions remain readable. Schema and regional conversion commit inside the existing owner's save transaction; a failed transaction rolls back the schema, payloads and cached write state together.

World format, laws, generator, clock, ownership, receipts and history remain separate from storage encoding. This operation creates no new physical archive. Freed pages become reusable; it does not shrink the database. Older storage-1 runtimes cannot load the new encoding. The [deployed gateway compatibility guard](gateway-readiness-0.2.md) prevents automatic fallback to incompatible code after a committed storage change.

The actual gateway container replacement exposed a separate observer defect: after one unsuccessful reconnect, the browser stopped retrying. The client now recreates an EventSource only when the browser declares it permanently closed, backing off from one second to thirty seconds. Native retries remain responsible for recoverable interruptions. Obsolete listeners are ignored and returning to the planet cancels retries. The last world, camera and selected community remain visible; the client cannot advance or reset the world's clock.

## Coherence review and limits

The structural review checks **953 Git-visible files**, **687 resolved import/asset edges** and **471 local Markdown links**, with no missing targets or detected layer violations. This does not establish physical validity or validate arbitrary runtime paths.

The storage version and column contract have one owner in `storage-format.ts`; ordinary Store loading, maintenance inspection and generic offline upgrade/renewal readers use the same region decoder. Historical fixed-revision evidence remains unchanged. No simulation module or physical parameter changes. The related [infant-food diagnostic](../research/infant-food-access-2026-10-09.md) identifies missing holder-to-recipient access and uncalibrated heat/growth coupling without claiming a historical death share or applying a biological correction.

Whole-region serialization, monolithic population metadata, archive growth, single-host failure, finite queues and combined live/preflight memory remain limits. The quota trials do not emulate live disk latency or a cgroup memory limit. One initial baseline harness failed because it retained the first full world while loading a second; releasing that unused world allowed the same 216 MiB heap limit to pass. The failed harness result is retained. This storage change is not a claim that massive civilizations are supported, or that extinct communities have recovered.
